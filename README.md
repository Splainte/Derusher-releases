# Derusher — installeurs

Extension Adobe Premiere Pro qui dérushe automatiquement un tournage.

Ce dépôt ne contient que les **installeurs** publiés à chaque version : le
panneau Derusher y cherche ses mises à jour. Le code n'est pas ici.

- Windows : `Derusher-Setup.exe`
- Mac : `Derusher-macOS.pkg`

Dernière version : onglet [Releases](../../releases/latest).
